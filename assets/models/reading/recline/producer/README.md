# Recline producer handoff

The accepted export remains byte-for-byte unchanged. `source-index.json` binds all 336 declared inputs to their retained locations and original SHA-256 hashes. It references existing durable pose evidence and unchanged repository inputs, and retains the remaining source ancestry here. Large JSON, NumPy archives and ancestor Blender files use lossless gzip wrappers; the index records both the stored wrapper hash and the original decompressed hash. No arrays, matrices, receipts or producer scripts were rewritten.

1. Run `python assets/models/reading/recline/producer/verify_sources.py` from the repository root to verify the complete inventory and every byte round-trip. This does not write files or render images.
2. The final editable Blender scene is `editable/source.blend`. Its original path and hash appear in the index. The associated authored bone frames, physical proof, four rendering input manifests and observed process receipts are retained or referenced by the same index.
3. Producer entry points are the recorded copies of `pose_complete_recline_author_v3.py`, `pose_complete_independent_render_v1.py` and `pose_complete_recline_export_v1.py`. Their original bytes are preserved. The author consumes its input manifest and creates a fresh scene directory; the renderer consumes a per-facing input manifest and creates a fresh raw rendering directory; the exporter consumes the completed rendering directory. The exporter refuses to replace an existing export.
4. Before rebuilding, restore gzip-wrapped inputs to the original repository-relative paths recorded in the index, in a separate working copy. Preserve the accepted export and receipts. The original scripts expect the recorded scratch layout, and bound JSON still contains the producing checkout's absolute Windows paths. A relocated rebuild needs fresh working input manifests with rebased paths and newly recorded hashes; do not alter the immutable receipts to simulate portability.
5. This handoff verifies durable source coverage, including the editable scene and exact producer inputs. It does not claim that a relocated rebuild has been executed or that new images have passed the original physical, fidelity or runtime checks. Rebuilding or changing the scene requires those checks again.
