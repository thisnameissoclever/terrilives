# Candidate 02: accepted static artwork

Primary and independent adversarial source, four-facing GPU and played-room
review accepted this candidate at a subjective 91/100. The longer, narrower
mattress reads better beside Bill and the nightstand. Facing, floor contact,
wall clearance and approach space passed; all model parts stay inside the
existing 2x2 footprint.

All source, image and saved-model hashes match the proof. The evaluated-scene
checker finds physical support contacts and catches four displaced parts.
The original model reloads successfully and its file hash remains unchanged.

The plain duvet is a minor style limitation. The 1.86 mattress is shorter than
the 2.07411 fully extended idle Sim. Static acceptance does not establish a
lying pose, two-body occupancy, bedding interaction or enter/exit animation.
Those remain required future work, with explicit fit checks in the README.

See `docs/assets/review-evidence/bedroom/double-bed.md` for runtime evidence
and regression results. Publication remains a separate gate.
