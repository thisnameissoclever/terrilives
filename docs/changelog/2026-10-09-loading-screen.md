# Loading screen and clearer graphics errors

Opening the game now shows what it is loading, step by step, instead of a blank screen. Graphics problems now come with plain instructions.

## New

- While the game starts, a loading screen names and numbers each step, for example "Step 7 of 10: Loading furniture and people". Downloads also show how many files are done and how much data has loaded, so a slow connection still shows progress. The screen disappears once the house has been drawn.
- On a phone with the browser's Desktop site setting on, a notice explains that everything is drawn small and how to switch back to the phone layout. Close hides it for good.
- If the graphics card stops working during a game, the game saves the household and says so, instead of freezing.

## Improved

- When the browser will not give the game a graphics device, the error screen explains the usual cause and how to fix it: restart the browser, then check its graphics settings.
- The furniture and people art now downloads several files at a time instead of one after another.
- A saved household with boards, tiles or carpet laid no longer loads all the art a second time before the house appears.
- The game starts sooner, especially on phones, because its first download is much smaller.
