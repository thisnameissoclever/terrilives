# Loading screen and a faster start

Opening the game now shows what it is loading instead of a blank screen, and the first load no longer downloads the art twice.

## New

- While the game starts, a loading screen names each step. While the art loads, it counts the pages and fills a progress bar. It disappears once the house has been drawn.

## Improved

- The game starts faster, especially on phones. The art used to load twice before the house appeared; now it loads once, and several pages download at the same time.
