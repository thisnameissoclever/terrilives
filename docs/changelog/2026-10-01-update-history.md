# Read the game's update history

Natural Causes has a changelog with dated, collapsible notes covering significant features, fixes, art and sound changes.

## Features & changes
- **Open Changelog from Options.** The button beneath New game and Help opens the update history in a new tab, keeping the current game open. [PR #192](https://github.com/thisnameissoclever/terrilives/pull/192)
- **Browse and share updates.** The newest two entries start expanded. Open individual entries, expand or collapse them all, switch between dark and light themes, or use an entry's permalink.
- **Read the earlier history.** The changelog includes significant changes from the first playable alpha onward.
