# Furniture placement and cutaway walls

Furniture editing and wall visibility received another pass so the house is easier to rearrange and inspect.

## Features & changes
- **Furniture editing has clearer placement feedback.** The builder supports moving furniture and rotating objects with authored facings, with placement checks before a change is committed. [PR #133](https://github.com/thisnameissoclever/terrilives/pull/133)

## Bug fixes
- **Walls reveal the interior during play.** Cutaway behavior and furniture overlap are checked together so walls do not hide the activity the player is trying to see. [PR #133](https://github.com/thisnameissoclever/terrilives/pull/133)
