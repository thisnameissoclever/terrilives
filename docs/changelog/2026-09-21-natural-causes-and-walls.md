# Natural Causes and editable walls

The game takes the name Natural Causes. Build mode gains wall editing, and traits have a clearer effect on autonomous choices.

## Features & changes
- **The game is called Natural Causes.** Existing saves and settings continue to use their original storage identifiers so the name change does not reset progress. [PR #86](https://github.com/thisnameissoclever/terrilives/pull/86)
- **Build, remove and open interior walls.** The Walls tool lets you edit interior edges and make doorways, with checks that preserve reachable objects and routes. [PR #95](https://github.com/thisnameissoclever/terrilives/pull/95)
- **Traits influence activity choices.** Personal affinity changes which activities a person finds appealing. [PR #87](https://github.com/thisnameissoclever/terrilives/pull/87)
