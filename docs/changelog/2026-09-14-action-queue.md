# See and manage queued actions

The selected person's Queue displays upcoming actions and holds up to ten orders.

## Features & changes
- **Upcoming actions are visible.** Inspect a person's queue to see what they have been told to do next. [PR #69](https://github.com/thisnameissoclever/terrilives/pull/69)
- **A person can hold ten queued orders.** The limit increases from four to ten. [Queue-limit change](https://github.com/thisnameissoclever/terrilives/commit/a02bb82b)
