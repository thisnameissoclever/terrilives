# Build mode exit played pass, 2026-10-17

A played check of the Leave Build mode dialog, the footer's leaving Confirm and Cancel, and the contextual Cancel that clears only the selection, driven in a Playwright-controlled Chromium window because the desktop app's browser pane was hidden and could not draw. The bundles were served by `vite preview` on port 4173, each rebuilt from its committed tree, and the Bundle column below names the commit each step was played on: `4d5c16047` (`index-Dy1HfXfB.js`); `ac69644ab` (`index-BMzvdbXq.js`), which made the Cancel beside a selection keep the batch and added the first double-click guard; `7fb478cb8` (`index-CbOnIfR1.js`), which moved the page-wide Escape handling into the dialog's controller and narrowed the guard; `cf6dd0a7a` (`index-Bs6RVfMa.js`), which ends the guard on a new click run and reads the causing click before any work; and `c029bb22c` (`index-DGenBk_3.js`), which arms the guard when a pointer click opens the dialog. Frame `02` comes from `4d5c16047` and frames `01`, `03` and `04` from `ac69644ab`; the dialog's markup and styles are unchanged across these commits. The household's money came from a schema-thirteen save of the shipped lot with $1,000,000, written into the page's save slot; the game's sound was muted. The game clock ran outside Build mode, so a $120 shift payment arrives between some steps, which is why the funds rise.
