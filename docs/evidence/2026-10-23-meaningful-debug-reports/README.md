# Meaningful error reports

The earlier recorder discarded errors after the first frame and bound sharing to an earlier snapshot. Initial regression tests produced four failures for those omissions and missing journal data. Architecture probes then exposed oversized compact storage, cyclic worker coordinates, stale worker-error coalescing and missed CRLF encoding cost. Each case received a failing test before its repair.

`verification.json` records the actual compiled Chrome exercise. The browser creates a buffer with invalid usage to produce a real `GPUValidationError`. A subsequently thrown JavaScript exception includes a cause. Both occur after successful loading. The report retains their actual messages, source operations, stack/cause details and recent logs. Activating Options, then Report bug creates the bounded draft containing the latest exception and cause. The native mail application is never opened. Clipboard verification uses an isolated transport and preserves the system clipboard.

Other compiled scenarios cover a deliberately injected persistent HTTP 503, deliberate renderer termination during loading, standalone report retrieval, blocked copying, downloading and ordinary startup with advancing game time. An injected response and intentional renderer termination verify diagnostics; they do not establish the cause of the reported iPhone crash. The selected screenshots were captured from the actual interface and read during review. `source.json` identifies the inspected inputs and compiled output.

The mail formatter budgets the entire encoded link to 8,000 characters and gives priority to the actual error and newest logs. The retained compact storage stays within 32,768 characters; pretty-printed copy/download exports can be larger. Regression cases include newline and Unicode expansion, long historical records, nested and cyclic errors, bounded source coordinates, changed worker evidence, repeat-write coalescing and fresh sharing after a later error.

Final clean-commit command results, selection, source/dependency identities and independent reviews are retained in ignored `.local-build/` storage and summarized in the pull request. Relevant checks cover web runtime, reporting instrumentation, public documentation and compiled browser behavior. Rust, WebAssembly source, artwork and dependency inputs are unchanged.

Physical iPhone execution, actual system clipboard transport and native mail-client acceptance remain unobserved.
