# Bounded mutation batch verification

These records cover the production batch limit, artifact sizing and authenticated capacity-failure handling. They follow the [native-admission implementation and forecast correction](../task-3-native-admission/fix1/README.md). They establish local code and review results, not actual Linux qualification or completed game mutation coverage.

The runner selects a deterministic prefix before starting work. Authenticated measurement fixes the maximum prefix size, and continuation preserves the original inventory, policy and lifetime. A completed prefix with work remaining reports incomplete progress. Outgoing capacity failure disables result upload, preserves the raw local bytes and retains a complete authenticated size-and-hash inventory in the failed producer's log. Later favorable results cannot erase that failure.

The [initial report](task-3-native-batch-budget-report.md), [quality finding](task-3-native-batch-budget-quality-review.md) and [scoped correction](task-3-native-batch-budget-fix1-report.md) retain their distinct boundaries. The correction compares observed execution payloads after substituting the same identity, so a long one-phase result cannot hide a larger two-phase result. The [spec re-review](task-3-native-batch-budget-spec-rereview1.md) and [quality re-review](task-3-native-batch-budget-quality-rereview1.md) approve the correction and test-fixture supplement.
