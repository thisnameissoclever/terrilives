# Glossary

## Player terms {#terms}

| Term | Meaning |
| --- | --- |
| Activity | What a person is doing now, such as walking, eating or reading. A longer order can contain several stages. |
| Affinity | One person's directional feeling toward another, from hostility to closeness. The other person's feeling is separate. See Relationships. |
| Autosave | An automatic write to the local save slot at the start of a new game day. |
| Bed assignment | Permanent ownership of a sleeping place. It is separate from current occupancy or a temporary reservation. |
| Bookmark | A person's saved progress through a reading pass. Interruption does not erase it. |
| Build draft | Home changes waiting for Confirm. Cancel at the bottom discards changes since the last confirmation. |
| Capability | A trait that permits a skill-linked chance of failure. Completed failed attempts can still give practice. |
| Chore | Actual work on dishes, floor grime, surface grime or bin waste. |
| Chore owner | The person responsible for a recorded duty. The performer may be somebody else. |
| Chore repair | Extra goodwill when the particular duty argued about is completed in time and the assigned person's work earns the reward. For dishes, that person must be the largest contributor and wash some dishes during the repair window; another person may wash the final plate. Ordinary cleaning appreciation is separate. See [chore repair](relationships/#chore-repair). |
| Cleanliness | A preference that affects mess tolerance and cleanup decisions. It is separate from the Hygiene need. |
| Company | Actual eligible participation with another person. Passive proximity, shared activity and conversation follow different rules. |
| Compatibility | How two people's activity preferences, dispositions and hobbies fit. It affects contact without directly setting their current feelings. |
| Condition | A trait with changing severity that can affect satisfaction accrual and mood. |
| Copy | One physical instance of a book. Owning several copies does not erase a person's familiarity with the title. |
| Decay | Gradual loss over game time. Needs fall; living relationships drift toward neutral; repetition fades. These have different rates. |
| Disposition | A trait or preference that changes the appeal of an activity. Reading-related dispositions also change how much Fun reading supplies. |
| Family tie | A partner, parent, child or sibling connection, separate from opinion. Family scales relationship events and adds a company bonus. |
| Familiarity | How much and how recently a person has read a title. Greater familiarity reduces novelty. |
| Funds | Household money used for purchases and increased by pay or sales. |
| Fumble | A failed capability-linked attempt. Positive benefits and satisfaction may be reduced or absent; costs and time still matter. |
| Game minute | The unit used for activity durations, need rates and the clock. Speed changes how many pass per real second. |
| Habituation | Repetition making the same activity on the same object less appealing. It fades over time without reducing ordinary need rates. |
| Hobby | A loved activity tag that increases completion-based life satisfaction. |
| Home shelf slot | The shelf place retained for a borrowed book until it returns. An empty-looking slot may already belong to a copy. |
| Hygiene | A person's current bodily cleanliness. Housework and the cleanliness preference are separate. |
| Grievance | An actual incident attributable to another person, such as a privacy violation or an overdue assigned chore. It gives an autonomous argument a subject. See [fights](relationships/#fights). |
| Life satisfaction | A longer-term assessment affected by sustained mood, rewarding activities, work, conditions and neglect. |
| Mastery | Progress in a skill, used for relevant capability checks. It differs from the displayed ladder level. |
| Model | A specific product, shown beneath its familiar object type. Different models can have different actions or rates. |
| Mood | How someone feels now, combining needs, conditions, environment, company and events. |
| Moodlet | One named reason contributing a positive or negative amount to mood. |
| Need | One of Hunger, Energy, Hygiene, Bladder, Social, Fun and Comfort. A fuller meter means the need is better met. |
| Novelty | How fresh a book feels to a particular reader. Switching physical copies does not reset it. |
| Order | An instruction you gave a person. It has priority over their autonomous choices. |
| Outside | The shared outdoor room name used for the yard and outdoor work. It does not make distant people passive companions. |
| Overdoing | Repetition beyond the usual appeal range, producing a mood penalty. Repeated excessive eating can also cause Feeling sick. |
| Performer | The person who actually completes a chore. Appreciation follows the performer, not automatically its owner. |
| Physical seat | A particular chair or sofa sitting place. Sitting, reading, meals and media share its availability. |
| Queue mode | New instructions join the end of waiting orders. With it off, new instructions go first while earlier waiting orders remain. |
| Reading pass | One journey from the beginning to the end of a title. It can span several sessions. |
| Reading session | One active period of reading. Completed sessions can provide skill practice; interrupted sessions keep progress without a completion attempt. |
| Reservation | A temporary claim on an object, person or destination. Someone travelling can already hold it. |
| Responsibility | A chore profile value affecting whether a person follows through on duties. It is separate from enjoying the chore. |
| Room association | A store grouping such as Kitchen or Yard. It does not restrict placement or grant actions. |
| Secondary seat | A real occupied chair used during another activity, such as TV or a meal, supplying its seating Comfort. |
| Severity | How strongly a condition is currently present. Appropriate completed activities can reduce it. |
| Shyness | A temperament value affecting privacy respect and reactions. It does not by itself establish compatibility. |
| Skill | Learned progress through completed attempts at an activity, such as Cooking, Fitness or Reading. |
| Taste | A person's lasting preference for book genres and particular titles. |
| Title | The authored book, distinct from one owned copy. Taste, familiarity and progress follow the person and title. |
| Type | The familiar physical kind of object, such as Armchair, Kitchen sink or Bunk bed. |
