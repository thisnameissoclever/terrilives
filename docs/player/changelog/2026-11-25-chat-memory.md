# Chat memory, and the game on Windows and Mac

Housemates now learn which topics each person enjoys, and you can install Natural Causes on a Windows PC or a Mac.

## New

- Housemates learn what each person likes and dislikes talking about, and steer their chats toward the topics the other person enjoys and away from ones they dislike.
- A more sociable housemate remembers more of their chats and makes better guesses about any topic they do not remember.
- Memories fade over about six game months unless another chat about the same topic brings them back. Games saved before this update start with nothing remembered.
- You can install Natural Causes on Windows and Mac. Download it from the Releases page of the game's GitHub project. The Mac app is notarized by Apple, and macOS may ask you to confirm once before it first opens; the Local install section of the project's README explains the warning Windows shows before the first install.
- The installed game plays offline and keeps your saved game as a file on your computer, so clearing browser data cannot remove it. Uninstalling the game leaves the save in place.
- In the installed game, time keeps passing while the window is minimized, and the game saves when you minimize or close it.
- Export save and Import save in Options move a game between the website and the installed game, in either direction.
- The installed game updates itself on Windows and Mac. It downloads a new version while you play and installs it when you close the game, and a note under the time says when the update is ready.

## Improved

- The version at the top of Options is now 1.1.0.
