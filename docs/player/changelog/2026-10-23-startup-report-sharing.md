# New address, save files and easier bug reports

Natural Causes is now at natural-causes.life, saved households can move between browsers and devices as files, and error details can be sent from Options, the failure screen or Startup report page.

## New

- Natural Causes has its own address: natural-causes.life. The old address opens the new one.
- Options has Export save, which downloads your household as a file.
- Options has Import save, which loads a save file after you confirm. It replaces the current game and your saved game in this browser.
- A save made at the old address can come along: open [Move your Natural Causes save](https://thisnameissoclever.github.io/natural-causes-old-save/) in the browser where you played, choose Download save, then use Import save at natural-causes.life. Do this soon, because some browsers clear saved data for sites you have not visited for a while.

## Improved

- Copy debug details copies the report for sharing with Tim. If copying is blocked, the details remain selectable.
- Email Tim opens a draft with the game version, recorded error and newest logs that fit.
- Report bug in Options prepares the same email while the game is open.
- Reports retain recent activity and errors after loading finishes.

## Fixed

- Bug report emails fit Gmail's draft-opening link, with the recorded error first and newest logs ahead of older details.
