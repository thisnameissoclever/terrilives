# New address and save files

Natural Causes is now at natural-causes.life, and saved households can move between browsers and devices as files.

## New

- Natural Causes has its own address: natural-causes.life. The old address opens the new one.
- Options has Export save, which downloads your household as a file.
- Options has Import save, which loads a save file after you confirm. It replaces the current game and the saved slot.
- A save made at the old address can come along: open [Move your Natural Causes save](https://thisnameissoclever.github.io/natural-causes-old-save/) in the browser where you played, choose Download save, then use Import save at natural-causes.life.
