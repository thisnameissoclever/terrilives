# Character creator name pool

Draft first names for owner review. Each name has a typically male, female, or either tag in the runtime pool. A new character receives a uniformly selected name from names matching the chosen gender plus the either category. Resolve randomized gender before an unlocked name. Name-only randomization uses the current gender; manual names and locked names remain unchanged when gender changes. The name field stays editable and has its own Random button and lock.

The requested groups contain 40 English/European selections, 40 selections familiar in the United States or Canada, and 20 less familiar selections with readable spellings. These groups guide selection; they do not claim exclusive origins, popularity rankings, or ethnicity. Many names are used across all these regions.
