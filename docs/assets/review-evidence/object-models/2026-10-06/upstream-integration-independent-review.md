Runtime and purchase facts instead classify these actions as `ActionAdmission::Exclusive` in `crates/terri-sim/src/beds.rs:29`, with capacity one at line 56 and exclusive admission at line 425.

   Causal witness: load the genuine `contended-tv-845101d.sav` at tick 65, migrate, and round-trip current V6 exactly. Bill, entity 35, remains seated with 37 ticks of TV work and his original lease. Change waiting Casey, entity 36, into a viewer of the same target, entity 17/action 0, at `(12, 1)`. Remove only Casey's waiting marker/order and replace her activity/position fields; preserve Bill, furniture, funds, RNG, clock, relationships and other people. The point satisfies the actual viewing cone, range, walkability and line-of-sight predicate. A Casey-only control accepts the same point. Current native adoption accepts the combined state and reproduces its snapshot exactly. The release WASM public loader also accepts and reproduces the forged V6 bytes exactly. Eleven off-grid/contact negative controls from the initial bounded scan reject with `InvalidGrid` and preserve the live snapshot/hash; truncated public input also rejects transactionally.

   This is **inherited**, not an integration regression. The actual 845101d source accepts and exactly round-trips the analogous V5 state. The current release also migrates that V5 state and round-trips its resulting V6. Existing public command contention evidence remains correct: the normal admission path cannot create this concurrent use. One tick after adoption retains two TV targets; Bill decreases to 36 ticks and Casey begins a viewing-position change. This probe does not claim that both remain seated or receive uninterrupted duplicate rewards forever.

   Smallest defensible correction: derive a current-format duplicate-target check from the same `ActionAdmission` classification, with a regression using the retained witness and a positive multiple-seat control. **Do not apply that guard indiscriminately to historical source validation or silently cancel either person's progress.** The accepted historical state demonstrates that tightening current adoption also requires a stated policy for source-admissible concurrent targets and the V6 states produced from them. Preserving that accepted contract and requiring exclusive current ownership cannot both be achieved merely by extending the existing Boolean guard. Resolve that compatibility scope before implementation. New communal media gameplay is not justified by this result. This finding blocks a claim of complete strict current ownership validation; it does not establish broken normal-play contention or invalidate the capacity-one purchase fact.
